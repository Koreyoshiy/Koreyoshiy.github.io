Welcome to [Hexo](https://hexo.io/)！这是博客创建时的第一篇文章。

查看 Hexo 的[官方文档](https://hexo.io/docs/)可以了解更多。如果遇到问题，可以阅读[故障排查](https://hexo.io/docs/troubleshooting.html)，或者前往 [GitHub](https://github.com/hexojs/hexo/issues) 提问。

## Quick Start

### Create a new post

```bash
hexo new "My New Post"
```

更多信息：[Writing](https://hexo.io/docs/writing.html)

### Run server

```bash
hexo server
```

更多信息：[Server](https://hexo.io/docs/server.html)

### Generate static files

```bash
hexo generate
```

更多信息：[Generating](https://hexo.io/docs/generating.html)

### Deploy to remote sites

现在博客由 GitHub Actions 自动构建部署。把源码推送到 `source` 分支后，无需手动运行 `hexo deploy`。
