按知识领域管理面试准备进度。可以筛选类别、完成状态和“需要复习”，每次复习后只需更新 YAML 数据。

{% interview_bank %}

## 如何更新

在 GitHub 网页编辑 [`source/_data/interviews.yml`](https://github.com/Koreyoshiy/Koreyoshiy.github.io/edit/source/source/_data/interviews.yml)：

- `status`：`未开始`、`学习中`或`已完成`
- `difficulty`：`基础`、`进阶`或`困难`
- `review: true`：标记为需要复习

需要写详细答案或面试复盘时，可以新建一篇文章，并把文章链接填写到题目的 `link` 字段。
